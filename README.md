# 商品上架結構表產生器

## 系統需求
- Python 3.8 以上
- 以下套件（安裝指令見下方）

## 安裝步驟

1. 解壓縮此資料夾到任意位置

2. 開啟終端機（Terminal / 命令提示字元），進入資料夾：
   ```
   cd excel_tool
   ```

3. 安裝所需套件：
   ```
   pip install flask openpyxl pillow pandas
   ```

4. 啟動伺服器：
   ```
   python app.py
   ```

5. 開啟瀏覽器，前往：
   ```
   http://localhost:5000
   ```

## 使用方式

1. **上傳原始資料檔**：將系統匯出的採購 Excel 上傳（需含商品編號、款號、尺寸、顏色等欄位）
2. **確認商品預覽**：系統自動解析並顯示所有商品清單
3. **上傳商品圖片**：依款號逐一上傳圖片（JPG/PNG/WebP 皆可）
4. **產生下載**：點擊「產生 Excel 下載」，自動輸出格式化完成的結構表

## 團隊共用方式

**方案A：區網共用（推薦）**
修改啟動指令為：
```
python app.py
```
app.py 已設定 host='0.0.0.0'，
啟動後其他人在同一區網輸入 `http://[你的電腦IP]:5000` 即可使用。

查詢本機 IP：
- Windows: 在命令提示字元輸入 `ipconfig`
- Mac/Linux: 在終端機輸入 `ifconfig`

**方案B：部署到公司伺服器**
將整個資料夾上傳到公司 Linux 伺服器，使用：
```
pip install gunicorn
gunicorn -w 4 -b 0.0.0.0:5000 app:app
```

## 注意事項
- 每次產生後檔案會直接下載，不會儲存在伺服器上
- 支援的輸入欄位：商品編號、款號、尺寸、顏色名稱、商品週數、週數日期、商品中分類、TW_1(官網)級別、TW_1(官網)頭單、特別要求
- 圖片格式：JPG、PNG、WebP
